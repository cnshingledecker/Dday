Source of truth and reproduction guide
======================================

Purpose
-------
This note marks the authoritative manuscript-facing state for the oxygen
ion-ice resubmission work as of 2026-04-21.

Authoritative baseline
----------------------
- Manuscript-native Model 1 input:
  `Model_1_kristen_corrected/`
- Paper source:
  `Ion_Ice_Paper/revisedVersion.tex`
- Paper figure inputs and bibliography:
  `Ion_Ice_Paper/`
- Same-model ion-on / ion-off paired data:
  `reviewer_response/comment_1.9_paired_kristen/`

Key numbers
-----------
- Ion-on baseline:
  `chi = 0.484166`, weighted RMSD `= 0.547233`, peak `O3/O2_0 = 23.547%`
- Ion-off control:
  `chi = 13.9327`, weighted RMSD `= 16.5804`, peak `O3/O2_0 = 3.243%`

Critical lineage decision
-------------------------
Kristen's Model 1 deck is the manuscript source of truth.
The older reviewer-control baseline with `chi = 2.011` and peak `26.8%` came
from a different `model.inp` and a different `photo_processes.dat`, and should
be treated as a separate reviewer-response artifact rather than as the paper's
Model 1.

Reproduction notes
------------------
- Use a clean worktree or temp copy.
- Run the model through `sh run.sh`, not by calling `singleRMSD.py` directly.
- Then evaluate `csv/bO3.csv` against the Gerakines points in
  `reviewer_response/comment_1.9_paired_kristen/eval_points.csv`.
- The repository is intentionally kept source-first; compiled PDFs and other
  large generated byproducts are not part of the archived source of truth.

Why `run.sh`
------------
`singleRMSD.py` can silently reuse a pre-existing `csv/bO3.csv` if the working
directory was not freshly cleaned. The safer provenance path is:
`clean -> run.sh -> inspect new csv output`.
